# Customer Churn Dashboard

📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze customer churn and identify the factors influencing customer retention. The dashboard provides key business metrics and visual insights to support data-driven decision-making.

---

🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling

---

 📊 Dashboard Features

- Total Customers KPI
- Churn Rate KPI
- Churned Customers KPI
- Churn by Tenure Group
- Customer Distribution by Churn
- Churn by Payment Method
- Churn by Contract Type
- Churn by Internet Service
- Interactive slicers for Contract Type and Gender

---

📈 Key Business Insights

- Total Customers: **7,032**
- Churned Customers: **1,869**
- Churn Rate: **26.58%**
- Customers with Month-to-Month contracts show the highest churn.
- Customers with shorter tenure are more likely to churn.
- Fiber Optic customers have higher churn compared to DSL users.
- Payment method shows noticeable differences in churn behavior.
